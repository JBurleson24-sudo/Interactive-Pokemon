# 🎮 Interactive Pokémon

A Unity-based interactive Pokémon application developed using C#.

## 📌 Project Overview

Interactive Pokémon is a Unity project that demonstrates interactive
game development using C# scripts, Unity scenes, assets, and user
interaction.

The project was developed as part of a mobile application/game
development course and demonstrates the use of Unity and C# to create
an interactive application.

## 🛠️ Technologies Used

- C#
- Unity
- Unity UI
- Unity Scenes
- Unity Asset System

## ⚙️ Key Features

- Interactive Pokémon application
- Unity-based game environment
- C# scripting
- Interactive scenes and objects
- User interface elements
- Custom project assets

## 📁 Project Structure

- `Assets/` — Main project assets, scripts, scenes, and resources
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project configuration

This project demonstrates my experience with:
